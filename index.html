Featured Project

AIBB — AI BunkerBuster

LLM 기반 자율 침투 테스트 시스템 · 팀장 (기획 · 설계 · 구현 · 실험 전 과정 주도)
설계 / 측정
  • Docker Manager · Scanner 연동 · Autonomous Attack Bot 핵심 모듈을 직접 개발하고 전체 공격 파이프라인 아키텍처를 설계
  • Scanner(Nmap + Nuclei) → LLM 페이로드 생성 → HTTP 공격 → 피드백 루프 자동화
  • Phase별 전략(basic → encoding → advanced → creative)으로 70회 자동 시도·실패 학습
  • 기존 도구 30% 대비 80%+ 성공률을 목표로, 피드백 루프 효과를 정량 측정
한계선 규명 — 단발 RCE(shellshock · ssti · thinkphp)는 자율 해결되나, 다단계 익스플로잇(spring4shell)은 정확히 진단하고도 완주에 실패. 이 지점은 소스코드 감사에서 사람의 판단이 집중되는 구간과 일치한다.
리얼월드 확장 — 블랙박스 실험에서 버그바운티·CVE로 범위를 넓히며 소스코드 도메인까지 확장. 타겟 선정 파이프라인이 오픈소스의 우선순위를 점수화했고, 그 선정에서 Portabase(9.8)·ArcadeDB(7.7)를 발굴 — 발굴 자체는 Claude Code와의 협업으로 수행.
